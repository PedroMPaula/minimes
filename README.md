# MiniMES

Sistema simplificado de gestão e acompanhamento da produção industrial, desenvolvido como projeto da disciplina de DevOps.

O objetivo do projeto é exercitar práticas de desenvolvimento, versionamento, testes, containerização e automação durante a evolução de um sistema de gestão da produção.

## Tecnologias

- Java 25
- Spring Boot 4.1.1
- Maven
- MySQL
- Docker
- Jenkins
- Git
- GitHub

## Status do projeto

**Release 0.1.0 — Projeto inicial**

Nesta versão foi criada a estrutura inicial da aplicação Spring Boot e implementado um endpoint para verificar o funcionamento da aplicação.
